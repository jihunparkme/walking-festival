너는 우리 팀의 리드 아키텍트(Lead Architect)야. `/init`을 통해 이 프로젝트를 분석해 줘.

너의 분석을 바탕으로 이 프로젝트의 **'헌법'이 될 상세한 `claude.md` 파일을 작성해줘.**

**작성 가이드라인:**

1. **`# Tech Stack`**: `package.json` 파일을 분석해서 사용된 핵심 프레임워크, 언어, 라이브러리 버전을 명시해줘. (Next.js, Tailwind, MDX 등)
2. **`# Code Style & Conventions`**: `src` 폴더 안의 실제 `.jsx`, `.js` 파일들을 읽고, 이 프로젝트가 따르는 암묵적인 코딩 스타일과 컨벤션을 추론해서 명시해줘.
    - 컴포넌트 정의 방식 (화살표 함수 등)
    - 스타일링 방식 (Tailwind CSS 클래스 사용법, `prose` 클래스 활용 등)
    - 데이터 렌더링 방식 (MDX 콘텐츠를 어떻게 파싱하고 화면에 표시하는지)
3. **`# SEO Principles`**: 이 프로젝트가 SEO를 위해 어떤 장치들을 사용하고 있는지 분석해줘. (`sitemap.ts`, `robots.ts`, 동적 OG 이미지 생성 등)

이 모든 내용을 종합해서, 새로운 팀원이 이 문서만 읽어도 프로젝트에 바로 기여할 수 있을 정도로 명확하고 상세하게 작성해줘.
